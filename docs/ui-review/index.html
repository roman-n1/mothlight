SQL и запуск — четвёртый этап

Сводка SQL с сортировкой, детали сохранённых выполнений и общая шкала запуска. Подписи интерфейса на русском и английском выбираются стандартными ресурсами Compose Multiplatform.

База — третий этап

Поиск таблиц, сетка данных, схема и изменения открытой страницы. Снимки сделаны в desktop UI-сценарии на базе Room 3 с тестовыми данными. Обновление и удаление прошли через DAO.

Логи — второй этап

Поиск по сообщению и тегу, совместные фильтры уровня и тега, полное сообщение и копирование записи или выборки. При чтении прокрутка приостанавливается, запись продолжается. Счётчик показывает новые подходящие записи, которые ещё находятся в буфере.

Mothlight после улучшений

Обновлены оболочка и HTTP. Объекты и массивы JSON сворачиваются независимо; состояние узлов сохраняется для каждого запроса и ответа. Эти снимки сохраняют состояние первого этапа. Обновлённый инспектор логов показан отдельно выше; SQL, запуск и база здесь демонстрируют изменение общей шапки.
